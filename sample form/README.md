# Test question extraction

From the repository root:

```powershell
python -m http.server 5500 --directory "sample form"
```

Open http://localhost:5500/index.html, choose a job, then click Apply Now.
Do not open the HTML directly as a file URL.

In Applyr: Job details → Continue to questions → Find questions on this page →
Generate answer drafts → review each answer → Fill webpage.
Click the Applyr toolbar icon on this website to grant page access before scanning.
A resume is needed for generating answers, not for finding questions.
